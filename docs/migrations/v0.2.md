# v0.2 migration and rollback

## Upgrade

1. Keep the existing `work/`, `final/`, `x2video.toml` and `.env` files.
2. Install the new package: `pip install -e ".[dev]"`.
3. Run `x2video doctor`.
4. Start Studio with `x2video studio` or create a Run with `x2video agent run`.

The first Agent command creates `work/x2video-agent.db`, enables WAL and applies additive migrations. v0.1 date-based outputs are not imported, moved or renamed. The legacy `fetch`, `curate`, `card`, `script`, `render` and `run` commands retain their paths and behavior.

## Rollback

Stop Studio and Workers, then install the earlier package or switch to the earlier Git revision. The old CLI ignores `work/x2video-agent.db`, `work/traces/` and `work/agent_runs/`. Keep these files if Run history may be needed; removing them deletes Agent-only history but does not affect legacy Publish Kits.

Prompt and Memory changes require explicit approval before use. Rejecting a pending Memory leaves its source feedback intact and prevents it from entering subsequent `ContentGoal.memory_context`.

## Troubleshooting

- Browser missing: install Playwright Chromium or set `X2VIDEO_BROWSER_EXECUTABLE` to an absolute executable path.
- FFmpeg missing: install both `ffmpeg` and `ffprobe`; Demo production and QC intentionally fail without them.
- Studio route returns JSON/404: run `npm run build` in `studio/` when developing from source; release packages include `x2video/api/static/`.
- Run is waiting: inspect its autonomy and Gate state, then approve/reject in Studio or use the API.
- Run failed after QC: inspect `quality_issues` and `publish_kit/qc.after.json`; unresolved blockers are intentionally not publishable.
